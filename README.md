# 🛡️ C2Eye - Monitor de Conexiones Maliciosas

## ¿Qué es C2Eye?

C2Eye es una herramienta portable que te permite monitorear TODAS las conexiones de red de tu computador en tiempo real. Es tu "segundo par de ojos" para detectar comunicaciones maliciosas que tu antivirus podría no ver.

## ¿Cómo usarla?

1. **Descarga** C2Eye.exe
2. **Ejecuta** el archivo (no necesita instalación)
3. **Observa** todas las conexiones activas en tiempo real
4. **Geolocaliza** cualquier IP haciendo clic en ella
5. **Mata** procesos sospechosos con un solo botón

## ¿Qué puedes hacer con C2Eye?

- ✅ Ver qué programas se están comunicando con internet
- ✅ Detectar conexiones a IPs sospechosas
- ✅ Geolocalizar servidores remotos
- ✅ Terminar procesos maliciosos al instante
- ✅ Aprender sobre conexiones de red

## Requisitos

- Windows 7, 8, 10 o 11
- No requiere instalación
- No requiere permisos de administrador (aunque algunos procesos avanzados sí)
